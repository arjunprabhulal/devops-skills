# .agents/ — Google Antigravity layout

This directory is GENERATED from the canonical `skills/` tree by
`scripts/build-antigravity.py`. Do not edit skills here directly — edit them under
`skills/<category>/<skill>/` and re-run the script.

`.agents/skills/<skill>/SKILL.md` is the layout Google Antigravity discovers in a
workspace. For a global install, copy any skill folder into `~/.gemini/config/skills/`.
