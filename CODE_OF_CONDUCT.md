# Code of Conduct

This project follows the [Contributor Covenant v2.1][covenant]. That document is the full text; it
is adopted here by reference rather than copied.

## Expected behavior

- Keep discussion on the technical substance: the skill, the wording, the command, the eval case.
- Disagree about content, not about people. "This command is wrong because X" is useful; "you are
  wrong" is not.
- Assume the other person read the same file and reached a different conclusion for a reason. Ask
  what it was.
- Accept review feedback on pull requests, and give it the same way — concretely, with the reason
  attached, as `AGENTS.md` asks of the skills themselves.
- Respect the scope of an issue or pull request. Open a separate one rather than redirecting a
  thread.

## Unacceptable behavior

- Harassment, insults, or personal attacks, in issues, pull requests, commits, or review comments.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Publishing another person's private information without their explicit permission.
- Sustained disruption: reopening settled decisions without new evidence, or derailing threads.

## Reporting

Report a concern in one of two ways:

- Open an issue at <https://github.com/arjunprabhulal/devops-skills/issues>. Use this when the
  matter can be discussed in public.
- Contact the maintainer, Arjun Prabhulal, directly through GitHub
  (<https://github.com/arjunprabhulal>). Use this when it cannot.

The maintainer reviews reports and decides on a response, which may include editing or removing
comments, closing a pull request, or blocking an account. Reports are handled in confidence.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
